# BtoB価格表作成ツール - ロジック仕様記録

本ファイルはアプリケーションの主要な計算ロジックやデータ構造を随時記録するためのドキュメントです。

## 1. データベーススキーマ設計 (IndexedDB)

データベース名: `BtoBPriceListDB`
バージョン: 1

### ストア構成

- **`customers`**
  - キーパス: `id` (Auto Increment)
  - インデックス: `parentId` (親子関係用), `type` ('client' | 'dealer')
- **`products`**
  - キーパス: `id` (Auto Increment / 製品ID)
  - インデックス: `category` (印刷時のグループ化に使用)
  - 項目: `name` (製品名), `price` (定価), `supplier` (仕入先), `code` (ｺｰﾄﾞ), `cd` (CD), `description` (説明), `remarks` (備考)
- **`constructions`**
  - キーパス: `id` (Auto Increment / 工事ID)
  - 項目: `name` (工事名), `price` (定価), `code` (ｺｰﾄﾞ), `cd` (CD), `description` (説明), `remarks` (備考)
- **`priceLists`**
  - キーパス: `id` (Auto Increment)
  - インデックス: `customerId` (対象顧客), `title` (検索用タイトル), `originalId` (過去バージョンのID・引継ぎ元)
  - 項目: `title` (価格表名), `customerId` (顧客ID), `createdAt` (作成日), `expirationDate` (有効期限), `version` (バージョン番号), `originalId` (元となった価格表のID), `status` ('active' | 'archived')
- **`priceListItems`**
  - キーパス: `id` (Auto Increment)
  - インデックス: `priceListId`
  - 項目: `priceListId` (価格表ID), `itemType` ('product' | 'construction'), `itemId` (製品/工事ID), `rate` (掛け率%), `specialPrice` (特価/直接入力金額), `displayMode` ('listPrice' | 'sellingPrice' : 価格表印刷時に定価表示するか価格表示するかを一項目ごとに選択)

## 2. 価格表のバージョン管理・検索ロジック

- **バージョン管理**:
  - 既存の価格表から「新しいバージョンを作成」する際、元のデータをコピーし `version` をインクリメントする。
  - その際、以前の掛け率 (`rate`) や特価 (`specialPrice`) を引き継ぐ。
  - `originalId` に大元の価格表（または直前の価格表）のIDを保存し、紐づけ（系譜）を追えるようにする。
- **検索**:
  - `title` (価格表名) や `customerId` に対して前方一致・部分一致による検索をUIで提供する。

## 2. 価格計算・表示ロジック (Readme.txt 整合性)

### 製品の算出方式

- **通常卸値**:
  - 基本となる取引価格。算出は「定価 × 掛け率（%）」または「直接金額入力」のいずれかを選択可能。
- **特価（単発・複数台対応）**:
  - 特別な案件や数量（複数台導入など）に応じた価格設定。通常卸値とは別に管理し、見積明細ごとに適用可能とする。
- **表示切替（定価・価格の選択）**:
  - 価格表作成時に、出力する金額を「定価表示(listPrice)」するか「（卸）価格表示(sellingPrice)」するかを、**一項目ごと（行ごと）に**選択可能とする。

### 工事の算出方式

- **`constructions`データベース**:
  - 製品同様に「定価」を保持・設定する。
  - 価格表作成時には「定価」に対して金額設定（掛け率や直接入力）を行い、項目ごとに定価表示か価格表示かを選択可能。

### 印刷・カテゴリ表示

- **カテゴリ別表示**:
  - 印刷時（またはPDF出力時）、製品データベースに登録された「カテゴリ」ごとに項目をグルーピングして表示する。

## 3. 見積期限・バージョン管理ロジック

- **見積期限切れ警告**:
  - 保存された `expirationDate` と当日を比較し、期限切れのものはダッシュボードおよび一覧で一目で分かるように強調表示（赤字・アラート。
- **ステータス管理**:
  - `active`（有効）と `archived`（アーカイブ）の2状態を持つ。
  - アーカイブされた価格表はダッシュボードの「有効な価格表」統計から除外され、整理目的で使用される。
- **バージョン管理と引継ぎ**:
  - 既存の価格表から「更新版（新Ver）」を作成する際、前回の「掛け率」や「直接入力金額」をデフォルト値としてコピー（引継ぎ）する。
  - `originalId` により過去の見積との紐づけを維持し、履歴を確認可能にする。
