# BtoB価格表作成ツール 開発ステータスと今後の要件 (2026-04-21)

## 1. 現在の実施済み作業
- **IndexedDB基盤の構築**: 顧客、製品、工事、価格表、明細の5つのストアを持つデータベースを実装。
- **メインUI (6タブ構成)**: ダッシュボード、顧客、製品、工事、価格表の管理・一覧画面。
- **マスター管理機能**: 各種情報の登録・編集・削除。
- **価格表・明細編集ロジック**: 
  - 製品（定価ベース）、工事（OPEN価格・卸値直接入力）の混在対応。
  - 明細ごとの「掛け率（%）」または「金額（直接入力）」の表示モード切替。
  - **仕入単価の追加**: 製品・工事マスタに仕入単価フィールドを追加し、原価管理が可能。
  - **粗利計算**: 明細編集画面において、卸価格に対する粗利（円）と粗利率（%）を自動表示（社内確認用）。
- **バージョン管理（新Ver）**: 既存の価格表をコピーし、掛け率等を引き継いだ新しいバージョンを作成する機能を実装。
- **ポータル統合**: 拠点ポータルへのメニュー追加、機能説明書の更新。

## 2. 今後の追加要件（次回以降の優先事項）

### 2.1 価格表の編集・閲覧制限
- **有効期限の編集**: 基本情報モーダルから後日修正可能とする。
- **期限切れのロック**: 有効期限が切れた価格表は、原則として明細の編集を不可とし、閲覧または新バージョン作成のみを許可する。

### 2.2 バージョン表示の最適化
- **最新版のみの表示**: 価格表一覧では、デフォルトで同じ内容の最新バージョンのみを表示し、リストをスッキリさせる。
- **旧Ver履歴ボタン**: 「以前のバージョンを確認する」ボタンを配置し、クリックで過去の履歴を一覧表示、または最新版の行を展開して表示する。

### 2.3 顧客別見積一覧
- **ドリルダウン**: 顧客一覧（取引先リスト）で社名をクリックすると、その顧客に対して作成された過去の見積・価格表が一覧で表示されるビューを追加。

### 2.4 販売店（二次店）向けの宛先処理
- **親属性の紐付け**: 販売店マスタに「親取引先（卸先）」を設定可能にする。
- **宛先表記の自動変更**: 
  - 宛先は「親取引先（例：株式会社OO様）」とする。
  - その横または下に「OO店 様向け」と自動的に付記し、適切なBtoB宛名を作成する。

### 2.5 特価見積の表現強化
- **二重表記**: 特価（通常とは異なる大幅値引き等）の見積においては、「通常卸値（定価×基準率）」と「今回の特価（直接入力値）」を併記し、どれだけお得かを顧客に明示するレイアウトを実装。

## 3. ファイル構成
- `index.html`: メイン構造、SPA、全画面のテンプレート、モーダルUI。
- `css/style.css`: Construction Field Hub 準拠のダークグレー系デザインシステム。
- `js/db.js`: IndexedDBの初期化、汎用CRUD処理。
- `js/app.js`: 各画面の描画、価格計算ロジック、モーダル制御、印刷制御。
- `logic.md`: 定価・工事・卸値の基礎計算ロジックドキュメント。
- `機能説明書.md`: ユーザー向けマニュアル。
