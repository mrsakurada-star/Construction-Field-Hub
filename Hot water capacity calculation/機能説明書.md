# 給湯能力計算システム v5.3 - 機能説明書

## 1. はじめに

本システムは、大規模施設（ホテル、介護施設、厨房など）の給湯負荷計算を自動化し、最適な給湯器の号数と台数を選定するためのエンジニアリングツールです。  
パーパス株式会社 設計資料073-8、および建築設備設計基準（建備）をベースとし、施設の種類や設置される器具（シャワー、洗面、厨房など）から、ピーク時に必要な給湯負荷をシミュレーションします。

専門的な知識が必要な計算を自動化し、設計の根拠となる「計算書（レポート）」を誰でも簡単に作成できることを目的としています。

---

## 2. 4つの計算パターン（Pat 1〜4）

施設の給湯方式に合わせて、以下の4つのパターンから選択して計算を行います。

| パターン | 名称 | 利用シーン |
| :--- | :--- | :--- |
| **Pat 1** | **直圧給湯方式** | 給湯器から直接各器具へお湯を送る、最も一般的な瞬間式給湯。シャワー・洗面・厨房カランの台数からパーパス基準のA/B比較方式で号数を算出します。 |
| **Pat 2** | **給湯循環方式** | お湯を配管内で常に循環させ、蛇口を開けてすぐにお湯が出る方式。配管全長からの**放熱ロス（10 W/m×全長）を自動加算**して号数を算出します。 |
| **Pat 3** | **貯湯タンク方式** | 大きなタンク（貯湯槽）にお湯を貯めて循環させる方式。器具の1時間消費量と施設タイプ別の同時使用率からリカバリー加熱能力を算出し、併せて推奨貯湯タンク容量も表示します。 |
| **Pat 4** | **ろ過昇温方式** | 大浴場の浴槽水をろ過・加熱して一定温度に保つ方式。浴槽容量と循環回数から熱交換器の維持能力、初期湯張り能力のいずれか大きい方で熱源機を選定します。 |

## 3. 基本的な操作手順

本システムは「プロジェクト」単位で計算を管理します。

### STEP 1：プロジェクト基本設定

- 施設名、作成者を入力します。
- **都道府県を選択**: その地域の冬期の最低給水温度（tc）が自動的に設定されます（全国対応）。
- **施設種別を選択**: 下記10種から選ぶことで、計算で使用する**同時使用率テーブルが全系統に一括適用**されます。

| 施設種別キー | 表示名 | 参照基準 |
|---|---|---|
| `bizhotel` | ビジネスホテル | パーパス 設計資料073-8 P.8 |
| `leisurehotel` | レジャーホテル | パーパス 設計資料073-8 P.8 |
| `nursing` | 介護・老健施設 | パーパス 設計資料073-8 P.8 |
| `sports` | スポーツ施設 | パーパス 設計資料073-8 P.8 |
| `hotel` | ホテル・旅館 | 建備基準補完 |
| `hospital` | 病院・医療施設 | 建備基準補完 |
| `school` | 学校・教育施設 | 建備基準補完 |
| `factory` | 工場・作業場 | 建備基準補完 |
| `apartment` | 集合住宅 | 建備基準補完 |
| `office` | オフィス | 建備基準補完 |

### STEP 2：系統（システムの塊）の追加

一つの建物の中に「客室系統」「厨房系統」のように異なる給湯システムがある場合、それぞれ個別に「系統」として追加して計算できます。
- 系統ごとに計算パターン（Pat 1〜4）と給湯温度（th）・機器号数を設定します。

### STEP 3：器具数・パラメータの入力

- **Pat 1・2（直圧/循環）**: シャワー・洗面・厨房カランの台数を入力します。台数入力のたびに、施設種別と台数に応じた**同時使用率がリアルタイムで表示**されます。
- **Pat 3（貯湯タンク）**: 器具テーブルに洗面台・シャワー・浴槽などを追加し、数量を入力します。配管長と必要な場合は循環配管ロス分も加算されます。
- **Pat 4（ろ過昇温）**: 浴槽の容量（m³）・個数・ろ過循環回数・二次側温度差などを入力します。
- 入力値が変更されるたびに自動的に再計算され、結果がリアルタイムで更新されます。

### STEP 4：レポート出力

- 「レポート出力」メニューを開くと、計算書（A4縦対応）が自動生成されます。
- 各系統の途中式・同時使用率・配管口径・機器台数・水道直結判定が全て記載されます。
- ブラウザの印刷機能（Ctrl+P）でそのままPDF保存や紙への印刷が可能です。

## 4. プロジェクトの保存と読み込み

入力したデータは、画面右上のボタンから管理できます。

- **「保存（JSON）」ボタン**: 入力データをJSONファイルとして保存。
- **「読込（JSON）」ボタン**: 保存したJSONファイルを読み込み、作業を再開。

> ※ サーバーにはデータは保存されません。作業内容は必ずご自身のPCにJSONで保存してください。

---

## 5. 単体計算（クイックツール）

トップページの「単体計算」メニューからは、プロジェクトを作成せずに特定の項目だけを素早く計算できます。

| タブ | 計算内容 |
|---|---|
| **シャワー・カラン** | 指定した温度と流量を出すのに必要な号数を算出 |
| **最大出湯量** | 給湯器の号数から特定の温度差で出せる最大流量を算出 |
| **浴槽湯はり** | 浴槽を指定時間で満たすために必要な号数を算出 |
| **混合水栓計算** | 給湯器の設定温度と水を混ぜた際の最終的な流量バランスを算出 |

## 6. 自動チェック・安全確認機能

### 6-1. 70kW 超え警告（火災予防条例）

計算結果の総ガス消費量が **70kW 以上**の場合、「火災予防条例に基づく届出が必要」の警告を自動表示します。

### 6-2. 水道直結可否の自動判定

系統の給湯方式に応じて、水道直結の可否（✅可 / ⚠️要確認 / ❌原則不可）を自動判定し、計算結果に表示します。

### 6-3. レジオネラ属菌 注意喚起

以下の条件を満たす系統について、レポート生成時に**赤枠の注意喚起**を自動表示します。

- 貯湯・循環ラインを持つ方式（Pat 2 / Pat 3 / Pat 4）
- 系統の給湯温度が **60℃以下**

> 衛生管理上、設定温度を60℃超へ引き上げるか、定期的な昇温殺菌等の対策を推奨します。

### 6-4. 膨張タンク選定（オプション）

系統設定で「膨張タンク計算を有効にする」にチェックを入れると、配管内水量と機器内水量を合計したシステム総水量から、パーパス基準の膨張係数 S を用いて推奨タンク容量を自動選定します。

## 7. 配管口径 自動選定

選定された機器台数から、パーパス 設計資料073-8 P.9 の配管口径テーブルに基づき、**推奨給水配管・給湯往き配管の口径**を自動表示します。

| 台数 | 給水 | 給湯往き | 最大総流量 |
|:---:|:---:|:---:|:---:|
| 1台 | 20A | 20A | 18 L/min |
| 2台 | 25A | 25A | 36 L/min |
| 3台 | 32A | 32A | 53 L/min |
| 5台 | 40A | 40A | 89 L/min |
| 10台 | 50A | 50A | 178 L/min |
| 15台 | 65A | 65A | 267 L/min |
| 20台 | 80A | 80A | 356 L/min |

## 8. 技術的な補足

- **号数の定義**: 1分間に1Lの水の温度を25℃上昇させる能力を「1号」と呼びます（約1.74kW）。
- **余裕係数 K**: 全方式共通で **K = 1.1**（パーパス 設計資料073-8 P.7 準拠）。
- **同時使用率**: 台数と施設カテゴリから動的補間で取得（固定固定U値廃止済み）。

## 10. 注意事項

- 全てのツールは**ローカル環境（ブラウザ）**で動作します。入力したデータは一時的なもので、ページを閉じるとリセットされます（必ずJSONで保存してください）。
- 推奨ブラウザ: Google Chrome, Microsoft Edge（最新版）
- 本計算書はピーク時の同時使用率を基準とした需要想定であり、実運用の負荷変動により差異が生じる場合があります。実際の機器選定・導入にあたっては専門の設備設計者・施工業者による確認を受けてください。
