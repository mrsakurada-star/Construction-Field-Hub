## 1. 🔴 器具別の必要号数（固定計算値）【新規追加】

**現状の問題点**:  
現在の `計算ロジック.md` には器具ごとの「1台あたりの号数」が定義されていない。設計資料073-8 P.7 に、パーパス基準の器具別号数が明確に記載されている。

**追加すべき計算定義**（基準給水温度：5℃固定）:

### ① シャワー・浴室カラン

```
出湯量  : 10 L/分
湯  温  : 42℃
水  温  : 5℃
必要号数 = 10 × (42 - 5) ÷ 25 = 14.8号 → 15号/台以上とする
```

### ② 手洗い（洗面）カラン

```
出湯量  : 6 L/分
湯  温  : 40℃
水  温  : 5℃
必要号数 = 6 × (40 - 5) ÷ 25 = 8.4号 → 9号/台以上とする
```

### ③ 厨房カラン

```
出湯量  : 10〜12 L/分
湯  温  : 60℃（混合栓なし。マルチ給湯器が直接60℃を供給する）
水  温  : 5℃
必要号数 = (10〜12) × (60 - 5) ÷ 25 = 22〜26.4号 → 25号/台以上とする
```

> **注意**: 業務用厨房カランは一般的に混合栓を使用しない。  
> 湯のカランからはマルチ給湯器が作る設定温度がそのまま出る。

### ④ ふろ給湯（大浴場・浴槽湯はり）

```
出湯量  : 浴槽湯量(L) ÷ 給湯時間(分)
湯  温  : 44℃ ／ 屋外浴槽の場合は 48℃
          ※浴槽自体が冷えているため使用温度41℃を想定し、高めに設定
水  温  : 5℃
必要号数 = 出湯量 × (44 - 5) ÷ 25
```

## 2. 🔴 台数選定フロー（A・B 比較方式）【新規追加】

**現状の問題点**:  
現在は Qhm 積算のみで台数を決定しているが、設計資料073-8 P.8 に「**一般器具合計（A）と大浴場（B）を別算し大きい方を採用する**」フローが明示されている。

**追加すべき台数選定フロー**:

```
【STEP 1】一般器具の合算号数（A）

  A = ( ①号数 × 器具数①× 同時使用率
      + ②号数 × 器具数②× 同時使用率
      + ③号数 × 器具数③× 同時使用率 ) × 1.1（余裕率）
  ※端数は切り上げ

【STEP 2】大浴場（B）

  B = ④号数 × 1.1（余裕率）
  ※端数は切り上げ

【STEP 3】台数決定

  採用台数 = MAX(A, B)
```

> **注意**: 余裕率は **1.1** を使用する。  
> （現在の `計算ロジック.md` の余裕係数 K=1.3 は大規模 ASHRAE 計算向けのもの。  
> 業務用マルチ向けはパーパス基準の K=1.1 を使用すること。）

## 7. 🟡 貯湯タンクへの配管接続設計ルール【新規追加】

**現状の問題点**:  
`計算ロジック.md` に貯湯タンクへの配管接続に関する設計ルールが記載されていない。

**追加すべき内容**（設計資料073-8 P.5-6）:

```
① 給湯還り配管と熱源機往き配管のタンクへの接続口を近くにしない。
  （熱源機の能力をフル活用させるために熱源機に往く水温を下げたいため）

② 補給水配管は基本的に「1次側循環ポンプとタンク」の間に接続する。
  タンクに接続する場合は下部に配管する。

③ 補給水配管をタンクに直接入れる場合、給湯還り配管はタンク上部に配管する。

※ 熱源機運転の燃焼時間を短縮させるために、タンク内の温水と冷水を
   できるだけ攪拌しないような配管が望ましい（成層化を維持する）。
```

## 8. 🟡 水道直結可否の判定ルール【新規追加】

**現状の問題点**:  
`計算ロジック.md` に水道直結の可否についての記載がない。

**追加すべき内容**（設計資料073-8 P.7）:

| システム種別 | 水道直結 | 備考 |
|---|---|---|
| 瞬間式（単管）単独設置 | ✅ 通常可能 | - |
| マルチ給湯器 複数台設置 | ❌ 通常不可 | 所轄水道局に問い合わせ要 |
| 即湯式（循環）配管システム | ❌ 通常不可 | 〃 |
| PU-6 等ポンプユニット使用 | ✅ 可能 | 給水装置の認証取得済みのため |

> **補足**: 給水装置の構造及び材質の基準に関する省令（厚生省令第14号）に合致していれば、水道直結が許可される場合がある。各市町村の水道局に問い合わせること。  
> また、専用掛け台（認証番号取得済み）を使用する場合は、**給水管口径を50A以上**とし、先太り配管は不可。

## 10. 🟠 膨張タンク選定計算式【新規追加】

**追加すべき計算式**（GYOMU P.93）:

$$V_{exp} = V_{sys} \times S$$

| 記号 | 意味 |
|---|---|
| $V_{exp}$ | 膨張タンク容量 [L] |
| $V_{sys}$ | システム内水量（配管 + 熱源機） [L] |
| $S$ | 水の膨張係数 |

**膨張係数 S の値**:

| 温度 | 膨張係数 S |
|---|---|
| 60℃ | 0.0151 |
| 70℃ | 0.0204 |

## 対応優先度に応じた更新手順の提案

1. **最優先（計算の根幹に関わる）**:
   - 器具別の固定号数計算値（①〜④）の定数をコードに登録
   - A・B 比較方式の台数選定ロジックに刷新
   - 施設別同時使用率テーブル（パーパス基準）を `data.js` に追加

2. **次点（設計精度の向上）**:
   - 余裕率 K の計算モード別切り替え（ASHRAE=1.3 / マルチ=1.1）
   - 機種別最大給湯量の機器データベースへの追加
   - 配管口径選定テーブルの補助表示機能

3. **その後（設計ガイダンスの充実）**:
   - 貯湯タンク配管設計ルールの注意事項モーダル等での案内
   - 水道直結可否チェックの入力フォーム追加

4. **最後（情報提供・コンプライアンス）**:
   - 膨張タンク選定補助ツールの追加
   - 法的届出要件の自動アラート（70kW超え時）
