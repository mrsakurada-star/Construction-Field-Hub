# `portal_update_logging` スキル

このスキルは、プロジェクト内の各ツールにアップデートがあった際、ユーザーがポータル画面（index.html）で最新の変更内容を把握できるように、`js/updates.js` を更新する手順を定義します。

## 1. 対象ファイル

- **`js/updates.js`**: アップデート履歴のデータソース。`PORTAL_UPDATES` 配列に新しいレコードを追加します。

## 2. 実装手順とチェックリスト

ツールの機能追加、バグ修正、UI改善が完了した直後に、以下の手順を実施してください。

### STEP 1: レコードの追加
- [ ] **配列の先頭に追加**: `PORTAL_UPDATES` 配列の一番上に新しいオブジェクトを追加します（降順表示のため）。
- [ ] **`toolId` の指定**: `js/tools.js` で定義されている `id` と一致させます（ポータル全体（Portal Core）自体の更新の場合は `portal` とします）。
- [ ] **日付の記載**: `YYYY-MM-DD` 形式で当日の日付を記載します。

### STEP 2: 内容の記述
- [ ] **`version` (任意)**: 必要に応じて `vX.X` 形式でバージョンを記載します。既存の `機能説明書.md` や `計算ロジック.md` と整合性を取ってください。
- [ ] **`changes` (変更点列挙)**: 実施した変更を箇条書き（文字列の配列）で記載します。

## 3. 記述のガイドライン

1. **ユーザーメリットの強調**: 単に「関数を修正した」ではなく、「〇〇のバグを修正し、安定性が向上しました」のように、利用者が受けるメリットが伝わる表現を心がけます。
2. **情報の鮮度**: 小さな修正でも、ユーザーが「開発が継続されている」と感じられるよう、こまめに記録を残します。
3. **正確な用語の使用**: 画面上のボタン名や機能名と、履歴内の名称を一致させます。

## 4. 記入例

```javascript
/* js/updates.js */
{
    toolId: "hot_water",
    toolName: "給湯能力計算",
    date: "2026-04-18",
    version: "v5.3",
    changes: [
        "業務用マルチ・器具数・ろ過昇温方式のUIデザインを統一",
        "同時使用率のリアルタイム計算・表示機能の実装"
    ]
},
```
