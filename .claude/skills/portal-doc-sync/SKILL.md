# `portal_doc_sync` スキル

このスキルは、プロジェクト内の各ツール（給湯計算、写真管理など）に機能追加や仕様変更があった際、ユーザーが迷わないようポータルサイトの表示とドキュメントを同期させるための手順を定義します。

## 1. 同期の対象ファイル

- **`js/tools.js`**: ポータル画面（index.html）のツールカードに表示されるタイトル、説明文、タグを管理します。
- **`機能説明書.md`**: 全ツールの詳細な機能と具体的な操作手順を網羅したドキュメントです。
- **`index.html` (ポータル)**: 特性が変わった場合や全体に関わる変更がある場合に更新します。

## 2. 実装手順とチェックリスト

ツールのアップデート（機能追加、バグ修正、UI変更など）を完了した直後に、以下の手順を実施してください。

### STEP 1: `js/tools.js` の更新
- [ ] **`desc` (説明文)**: 新機能や改善点を短い文章（2〜3行）で反映します。
- [ ] **`tags` (タグ)**: 関連するキーワードを追加・削除します。
- [ ] **`icon` / `title`**: ツール名が変更された場合や、より適切なアイコンがある場合は変更します。

### STEP 2: `機能説明書.md` の更新
- [ ] **対象ツールのセクション**: 該当するツールの「主な機能」および「使用方法」を、最新の状態（vX.X表記など）に書き換えます。
- [ ] **算定根拠の追記**: 計算ロジックが変更された場合は、その基準（パーパス基準、JIS等）を明記します。
- [ ] **UI手順の整合性**: ボタン名や配置が変わった場合、操作手順の説明もそれに合わせます。
- [ ] **最終更新日の更新**: ファイル最下部付近にある「最終更新: YYYY年M月D日」を当日の日付に更新します。

### STEP 3: ポータル `index.html` の確認
- [ ] **動的表示の確認**: 全体的なツールの数やカテゴリに変化がないか確認します。
- [ ] **全体への通知**: 必要に応じて、ポータルのヘッダー等にアップデート情報を追記します。

### STEP 4: アップデート履歴（js/updates.js）の更新
- [ ] **履歴への記録**: [portal_update_logging スキル](../portal_update_logging/SKILL.md) の手順に従い、今回の変更内容を履歴データに追加します。

## 3. 記述のガイドライン

1. **専門性と平易さの両立**: 技術的な詳細（IndexedDB、Pat3ロジック等）を記載しつつ、現場担当者が理解しやすい言葉を選びます。
2. **視覚的な区別**: Markdownの `> [!IMPORTANT]` や `> [!TIP]` などのアラートを使い、重要な注意点を強調します。
3. **リンクの整合性**: `tools.js` の `url` が正しいディレクトリ・ファイル名を指しているか必ず確認してください。
