# スキル：シンプルデザインと統一アイコンの適用 (Simple Design & Unified Icons)

このスキルは、プロジェクト全体の視覚的な一貫性を保ち、プロフェッショナルでクリーンなユーザーインターフェース（UI）を構築するためのガイドラインを提供します。

## 1. アイコンの標準化 (Lucide Icons)

絵文字や不揃いの画像アイコンの代わりに、**Lucide Icons** を使用します。これにより、シンプルで均一な線画スタイルのアイコンが提供されます。

### 導入方法

HTMLの `<head>` 内に以下のCDNスクリプトを追加します：

```html
<script src="https://unpkg.com/lucide@latest"></script>
```

### 使用方法

`<i>` タグまたは `<span>` タグに `data-lucide` 属性を指定します：

```html
<i data-lucide="check-square"></i>
<i data-lucide="file-text"></i>
```

ページ下部の `<script>` 内で初期化を実行します：
```javascript
lucide.createIcons();
```

## 2. デザイン・配色規格（Purpose Ecotech トークン, 2026-07-03 リデザイン）

過度なグラデーションや鮮やかな色は避け、落ち着いたプロフェッショナルな配色を採用します。
`css/portal.css` のトークンを正とする（`design-system.css` は旧オレンジ系トークンの残骸でレガシー、参照しないこと）。

### 基本カラーパレット
| 変数名 | 色 | 用途 |
| :--- | :--- | :--- |
| `--ink` | `#1A1A1A` | メインテキスト・見出し |
| `--ash` | `#6E6E73` | 補足テキスト |
| `--ash-2` | `#9B9A97` | さらに弱い補足・プレースホルダー |
| `--clay` | `#A8572E` | アクセントカラー（ボタン・強調・リンク） |
| `--mist` | `#F6F5F3` | ページ背景・カード背景 |

### タイポグラフィ
- 日本語: `Noto Sans JP`（本文）/ `Noto Serif JP`（見出し・強調したい箇所）
- 英数字: `Inter`

### 形状・モーション
- `border-radius: 0`（角丸なし。カード・ボタン・入力欄すべて直角）
- ボーダーは `1px` のヘアライン罫線で区切る（太いボーダーやドロップシャドウの多用は避ける）
- トランジションは `200ms` を基本とする

---

## 3. レイアウトの原則

1. **ヘッダー**: 派手なグラデーションは避け、`--mist` 背景に `--ash` の1pxヘアラインで区切るシンプルな構成にします。
2. **カード**: 角丸なし（`border-radius: 0`）、1pxヘアラインボーダー、ホバー時は200msのわずかな変化で奥行きを表現します。
3. **タイポグラフィ**: `Noto Sans JP` / `Noto Serif JP` と `Inter` を組み合わせ、読みやすさを最優先します。

---

## 4. 適用ルール

- 新しいツールを作成する際、または既存のツールを修正する際は、必ずこの規格に準拠させること。
- 「派手・複雑」よりも「使いやすさ・清潔感」を重視すること。
- 旧オレンジトークン（`--accent #ff9500` 等）を見つけたら、このセクションの Purpose Ecotech トークンへ置き換えること。
