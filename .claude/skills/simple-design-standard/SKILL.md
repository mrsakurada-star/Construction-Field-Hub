# スキル：シンプルデザインと統一アイコンの適用 (Simple Design & Unified Icons)

このスキルは、プロジェクト全体の視覚的な一貫性を保ち、プロフェッショナルでクリーンなユーザーインターフェース（UI）を構築するためのガイドラインを提供します。

## 1. アイコンの標準化 (Lucide Icons)

絵文字や不揃いの画像アイコンの代わりに、**Lucide Icons** を使用します。これにより、シンプルで均一な線画スタイルのアイコンが提供されます。

### 導入方法

HTMLの `<head>` 内に以下のCDNスクリプトを追加します：

```html
<script src="https://unpkg.com/lucide@latest"></script>
```

### 使用方法

`<i>` タグまたは `<span>` タグに `data-lucide` 属性を指定します：

```html
<i data-lucide="check-square"></i>
<i data-lucide="file-text"></i>
```

ページ下部の `<script>` 内で初期化を実行します：
```javascript
lucide.createIcons();
```

## 2. デザイン・配色規格

過度なグラデーションや鮮やかな色は避け、落ち着いたプロフェッショナルな配色を採用します。

### 基本カラーパレット
| 変数名 | 色 | 用途 |
| :--- | :--- | :--- |
| `--bg` | `#f8f8f6` | ページ背景 (オフホワイト) |
| `--white` | `#ffffff` | カード・セクション背景 |
| `--text` | `#1a1a18` | メインテキスト |
| `--text-muted` | `#6b6b60` | 補足テキスト |
| `--border` | `#e2e2dc` | ボーダー・区切り線 |
| `--accent` | `#2a2a24` | アクセントカラー (ボタン・強調) |

---

## 3. レイアウトの原則

1. **ヘッダー**: 派手なグラデーションは避け、白背景に下線（ボーダー）のシンプルな構成にします。
2. **カード**: 角丸は小さめ（4-6px）にし、薄いボーダーとホバー時のわずかなシャドウで奥行きを表現します。
3. **タイポグラフィ**: `Noto Sans JP` と `Inter` を組み合わせ、読みやすさを最優先します。

---

## 4. 適用ルール

- 新しいツールを作成する際、または既存のツールを修正する際は、必ずこの規格に準拠させること。
- 「派手・複雑」よりも「使いやすさ・清潔感」を重視すること。
