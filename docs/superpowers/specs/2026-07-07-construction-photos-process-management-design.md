# Construction photos — 工程管理機能 設計

## 背景

Construction photos（工事写真報告書作成ツール）の引継ぎメモ（2026-07-06）にある次回作業予定3件のうち、最初の1件「工程管理機能追加」の設計。既存コードはビルドなしの vanilla JS/HTML/CSS。データはメタ情報を localStorage、画像 src を IndexedDB に保存する構成（`js/storage.js`, `js/db.js`）。

## 要件

写真1枚は「1つの工程」に属し、その工程内で「前・中・後」のいずれか1つの状態（phase）を持つ。工程は現場ごとに自由入力する作業項目名（例：「基礎工事」「配管工事」「仕上げ工事」）で、固定テンプレートは持たない。

PDF出力では工程ごとにグルーピングし、各工程内は前→中→後の順で写真を並べる。

## データモデル

### 工程マスター

```js
processes = [{ id: number, name: string }]
```

- `js/common.js` の `STORAGE_KEY` 名前空間を再利用し、既存の cover/photosMeta/photoOrder と同じ localStorage オブジェクトに `processes` と `processOrder`（`processes` の並び順を表す id 配列）を追加する。
- 工程が0件の状態を許容する。0件のときは写真管理タブが従来通りのフラットリスト表示にフォールバックする。

### 写真オブジェクトの拡張

既存の `{id, src, name, date, exifDate, title, desc}` に以下を追加する。

```js
{
  ...,
  processId: number | null,   // 未割当は null
  phase: 'before' | 'during' | 'after'  // デフォルト 'before'
}
```

### 後方互換性

`processId` / `phase` を持たない既存データ（localStorage に保存済みの過去データ）をロードする際は、`processId: null`, `phase: 'before'` として扱う。マイグレーション処理は不要（読み込み時にデフォルト値を補完するのみ）。

## UI設計

### 表紙タブ（cover）— 工程マスター管理

「工事情報」セクションの下に「工程一覧」セクションを新設する。

- テキスト入力 + 「追加」ボタンで工程を新規登録する。
- 登録済み工程は一覧表示され、各行に削除ボタン・上下移動ボタン（並べ替え）を持つ。
- 工程削除時、その工程に割り当てられていた写真は `processId: null`（未分類）に戻す（写真自体は削除しない）。

### 写真管理タブ（photos）— グルーピング表示

写真リストを「工程 → phase（前/中/後）」の階層でグルーピングして表示する。

- 各工程ごとに見出し（工程名）を表示し、その下に「前」「中」「後」の3小見出し＋該当写真カードを並べる。
- `processId: null` の写真は先頭に「未分類」セクションとして表示する。
- 各写真カードに「前/中/後」切り替えタブ（3ボタン）を追加し、クリックで即座に `phase` を更新する。
- 写真カードは工程見出し（ドロップ対象領域）へドラッグ&ドロップ可能。ドロップすると当該写真の `processId` がその工程の id に更新される（`phase` は現在値を維持、未設定なら `'before'` のまま）。
- アップロード直後の写真は常に未分類（`processId: null`）として追加される。既存の EXIF 自動取得・工事日自動設定の挙動は変更しない。
- 工程内・同一 phase 内での並べ替えは、既存の上下移動ボタン（`movePhoto`）を維持する。並べ替えは photos 配列全体の順序（`photoOrder`）に対する操作のままとし、表示上のグルーピングとは独立させる。

### 並べ替えページ（reorder.html）

このフェーズでは変更しない。工程管理機能は写真管理タブと表紙タブの変更に閉じる。

## PDF出力への反映

- 出力直前に、`photos` 配列を「(1) 工程の並び順（`processOrder`、未分類は最後） → (2) phase順（before → during → after） → (3) 工程内・phase内は既存の手動並び順（photos配列内での相対順序）」でソートしたコピーを作成し、それをレンダリングに使う。`photos` 本体の並び順（写真管理タブでの表示順・movePhoto操作対象）は変更しない。
- 各工程の最初のページに工程名を見出しとして表示する。既存の `buildReportPage` 内、「工　事　名」テーブル行の下に「工　程」行を追加し、直前のページと工程が変わったタイミングでのみ工程名を表示する（同じ工程が複数ページに跨る場合、2ページ目以降は空欄）。
- 未分類の写真は最後に「その他」セクションとして出力する（工程名欄は空欄のまま）。

## 対象外（スコープ外）

- 引継ぎメモの残り2件（写真の複数選択機能、工事報告補足入力）は別途設計する。
- 並べ替えページ（reorder.html）への工程表示・フィルタリングは対象外。
- 工程テンプレートの事前定義機能は対象外（自由入力のみ）。
