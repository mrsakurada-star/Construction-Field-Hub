# 大規模現場工事指示書 作成ツール 設計書

> 作成日: 2026-06-16

## 1. 目的・背景

複数業者が同時入場する大規模現場（新築・改修等）において、現場概要・現場地図・業者別の作業予定・持参品・注意事項を一元化した「工事指示書」を作成し、A4印刷/PDFで各業者に配布するためのツール。Construction Field Hub ポータルに12番目のツールとして追加する。

## 2. ツール形式

- 既存ツール（工事写真報告書作成ツール、統合チェック表など）と同じパターンの、CFHポータル内の単独HTML/JSツール。
- `js/tools.js` にツール定義（id, title 等）を追加し、ポータルのツール一覧から起動できるようにする。
- データはIndexedDBに一時保存（ページ再読込・再訪問時も内容を保持）。最終的な配布物はA4横の印刷/PDF出力。

## 3. 画面構成・入力項目

本ツールは印刷時に2枚（A4横×2ページ）構成とする。

- **1枚目「現場概要」**: 表紙・現場概要（3.1）＋現場地図（3.2）＋全体注意事項・特記事項（3.6）。現場の共通情報・地図・説明を集約する。
- **2枚目「工事指示書」**: 業者一覧（3.3）＋工程表（3.4）＋持参品・注意事項（3.5）。各業者への工事連絡を集約する。

画面表示時はスクロールで両ページの内容を確認できるようにし、印刷時はページ単位で改ページする。

### 3.1 表紙・現場概要
- 自社管理番号
- 工事名／現場名
- 現場住所
- 工期（開始日〜終了日）
- 発注元
- 現場責任者名・電話番号（緊急連絡先）
- 作成日・作成者

### 3.2 現場地図
- **画面表示**: 住所を入力すると Google Maps のクラシック埋め込み形式（APIキー不要の `/maps?q=...&output=embed` 形式 iframe）を表示する。
- **印刷／PDF出力時**: iframeはprint CSSで除外されるため、以下を表示する。
  - 現場地図画像のアップロード枠（画像があれば印刷にそのまま使用。他ツールのIndexedDB画像保存パターンに合わせる）
  - 画像が未アップロードの場合は「Google Mapsで開く」リンクのURLと、そのURLのQRコードを印字し、現地で業者がスマホで開けるようにする。

### 3.3 業者一覧（業者グループ＋工程行）

同一業者が複数日・複数工程（例：電気工事業者が初日に配線、後日に給湯器接続）を行うケースに対応するため、「業者」を上位グループとし、その下に「工程」を複数紐づけられる2階層構造とする。

- **業者グループ**（業者ごとに1つ）
  - 業者名
  - 担当者名
  - 電話番号
- **工程行**（業者グループの下に複数追加・削除可能）
  - 作業内容／担当領域（例：電気工事／管工事／内装工事など、自由記述。同一業者でも工程行ごとに異なる内容を設定できる）
  - 入場予定日時
  - 退場予定日時

業者・工程の件数が多い場合、印刷時は自動で複数ページに改ページする（他ツールのA4自動可変レイアウトの考え方を踏襲）。

### 3.4 工程表（ガントチャート）

- 3.3で入力した各工程行の「入場予定日時」「退場予定日時」をそのまま集計し、追加入力なしで自動生成するガントチャート形式の工程表セクション。同一業者の複数工程もそれぞれ個別のバーとして表示される。
- **時間軸の粒度**: 時刻単位（1日の中で時間帯ごとに業者の在場バーを表示）。
- **複数日対応**: 作業期間が複数日にわたる業者がいる場合、日ごとにカードを分けて縦に並べる（1日＝1つの時刻軸タイムライン）。横軸に日付＋時刻の両方を取る連続ガントチャートは採用しない。
- 各日カード内では、縦軸に「業者名＋作業内容」（同一業者の複数工程は別行で表示）、横軸に時刻（例：8:00〜18:00）を取り、工程ごとの在場時間をバーで表示する。
- 業者一覧のデータ変更（業者追加・予定変更）に応じて自動的に再計算・再描画される（手動同期不要）。
- 印刷時は日ごとにカード単位で改ページ判定し、A4横1ページに収まらない場合は次ページに送る。

### 3.5 持参品・注意事項
- **共通チェックリスト**: 全業者に共通する持参品・注意事項のチェックリスト（自由に項目追加・削除可能）。
- **業者別セクション**: 業者一覧で登録した各業者ごとに、個別の持参指示・注意事項を自由記述またはチェックリスト形式で入力できる欄を設ける（業者ごとにタブまたはアコーディオンで切替表示）。

### 3.6 全体注意事項・特記事項
- 自由記述のメモ欄（現場特有の注意点、立入禁止区域、安全対策など）。

## 4. データ保存

- 既存ツール（工事写真報告書作成ツール等）と同様、IndexedDBを使用してフォーム入力内容・地図画像を保存する。
- ページを閉じても入力内容が保持され、再訪問時に復元される。
- 明示的な「クリア」操作で初期化可能とする。

## 5. 出力（印刷／PDF）

- A4横レイアウトを基本とする（業者一覧・工程表ガントチャートの横幅を確保しやすいため）。
- 「現場概要」「工事指示書」の2枚構成とし、3.の通り1枚目＝現場概要（3.1＋3.2＋3.6）、2枚目＝工事指示書（3.3＋3.4＋3.5）の順で印刷する。
- 業者数・持参品項目数・工程表の日数に応じて、2枚目「工事指示書」は自動的にページが増減する可変レイアウトとする（`a4_print_adjustment` スキルの方針に従う）。
- ブラウザの印刷機能（Ctrl+P）でPDF保存・印刷の両方に対応する。

## 6. 既存ツールとの整合性

- ポータルへの登録: `js/tools.js` にツールエントリを追加。
- A4印刷調整: `.agents/skills/a4_print_adjustment/SKILL.md` の方針を踏襲。
- 構造のモジュール化: `.agents/skills/structural_modularization/SKILL.md` の方針を踏襲。
- ポータル側のドキュメント更新: `.agents/skills/portal_doc_sync/SKILL.md` に従い、`機能説明書.md` にツール12として追記する。
- 著作権表記: `.agents/skills/copyright_insertion/SKILL.md` に従う。

## 7. レイアウト仕様（実装イメージ・1枚目「現場概要」ヘッダー部）

実装中のプロトタイプのヘッダー・基本情報部分のレイアウトを、3章の2ページ構成方針に合わせて採用する。A4横、2カラム構成。

```
┌─────────────────────────────────────────────────────────────────┐
│ 現場概要                            文書 NO.[000]  発行日[2026-06-16] │ ← オレンジ帯ヘッダー
├───────────────────────┬─────────────────────────────────────────┤
│ 工事名  [工事名を入力してください]   │ 現場地図                              │
│ 現場住所 [住所を入力]               │ （Google Maps埋め込み／印刷時は       │
│ 工事日程 [開始日] 〜 [終了日]        │  画像アップロード or QRコード／3.2）   │
│ 集合時間 [例: 08:00 — 現場集合]      │                                       │
├───────────────────────┴─────────────────────────────────────────┤
│ 現場概要                                                          │
│  現場の概要・条件                                                  │
│  建物種別・規模                                                    │
│  （全体注意事項・特記事項／3.6）                                     │
└─────────────────────────────────────────────────────────────────┘
```

- **ヘッダーバー**（オレンジ色帯）: 左に大見出し「現場概要」、右に「文書NO.」（自社管理番号、3.1に対応）と「発行日」を表示。同じヘッダースタイルを2枚目「工事指示書」にも適用する。
- **左カラム（基本情報）**: 工事名、現場住所、工事日程（開始日〜終了日）、集合時間（時刻＋集合場所の自由記述）。3.1の項目のサブセットに対応。
- **右カラム**: プロトタイプでは工程表グリッドを配置していたが、3章の方針に従い2枚目「工事指示書」へ移動する。1枚目の右カラムには現場地図（3.2）を配置する。
- **下段「現場概要」**: 「現場の概要・条件」「建物種別・規模」などの自由記述欄＋全体注意事項・特記事項（3.6）。

2枚目「工事指示書」は、プロトタイプの「工程表 — SCHEDULE」グリッド（業者×時間帯のセルをクリックして塗りつぶす操作型UI）を3.4の工程表セクションとして採用し、3.3の業者一覧（業者グループ＋工程行）・3.5の持参品・注意事項と合わせて配置する。工程表のセル塗りつぶしは、3.3で入力した入退場日時からの自動描画に加えて、セルクリックによる手動上書きにも対応する。

## 8. スコープ外（今回は対応しない）

- Google Maps Directions API等を用いたルート案内表示。
- 業者への自動通知（メール・SMS送信）機能。
- 複数現場をまとめて一括管理する機能（本ツールは1現場＝1指示書を前提とする）。
